# HTML Parser & Web Crawler

Десктопное приложение на C# для парсинга HTML-страниц и обхода сайтов (Web Crawling) с удобным графическим интерфейсом на базе **Windows Forms**.

![C#](https://shields.io)
![Platform](https://shields.io)
![UI](https://shields.io)

---

## Возможности

- **Парсинг HTML-страниц** — извлечение нужных данных и ссылок с веб-страниц.
- **Встроенный Web Crawler** — автоматический обход внутренних страниц сайта по заданной ссылке.
- **Ротация User-Agent** — поддержка списка заголовков из файла `useragent.json` для имитации реальных браузеров.
- **Графический интерфейс** — наглядное управление процессом без использования консоли.
- **Автоматическое сохранение** — все собранные результаты сохраняются в системную папку **«Мои документы»** (`Documents`).

## Быстрый запуск (для пользователей)

1. Перейдите в раздел **[Releases](../../releases)** справа и скачайте архив с последней версией программы (`HtmlParser-v1.0.0.zip`).
2. Распакуйте архив в любую удобную папку.
   > **Важно:** не удаляйте и не перемещайте файл `useragent.json` и библиотеки `.dll` — они должны находиться в одной папке с `htmlParser.exe`.
3. Запустите **`htmlParser.exe`**.
4. После завершения парсинга готовые файлы с результатами ищите в папке **`Документы` (Мои документы)** на вашем ПК.

## Сборка из исходного кода (для разработчиков)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Откройте файл решения **`htmlParser.slnx`** в **Visual Studio**.
3. Восстановите NuGet-пакеты (при необходимости) и соберите проект (`Ctrl + Shift + B`).
